A modern, full-featured **School Management &amp; Institutional Cloud ERP Platform** designed for educational institutions, educators, students, and parents. Combines an institutional public website with a role-based academic portal featuring digital attendance, online fee transactions, timetable tracking, dynamic marksheets, and student performance analytics.

## ✨ Key Features & Capabilities

### 🏛️ 1. Modern Institutional Public Website
- **Institutional Profile:** Mission, vision, leadership, and 25+ years legacy.
- **Academic Wings:** Pre-Primary, Primary, Middle School, and Senior Secondary Streams (Science PCM/PCB, Commerce, and Humanities).
- **Interactive Admissions:** Step-by-step application workflow with an integrated dynamic **Annual Fee Calculator**.
- **Campus &amp; Infrastructure:** Smart 4K classrooms, AI/Robotics maker-labs, digital knowledge libraries, and athletic sports complexes.
- **Photo &amp; Event Gallery:** Category-filtered campus moments, sports tournaments, and science exhibitions.
- **Inquiry &amp; Contact Desk:** Interactive parent inquiry submissions and location guides.

### 📊 2. Integrated School Cloud ERP
- **Multi-Role Switching:** Seamlessly toggle between **Student**, **Teacher**, **Parent**, and **Super Admin** modes.
- **Attendance Tracker:** Biometric sync simulation, monthly percentage calculations, and attendance logs.
- **Weekly Dynamic Timetable:** Real-time period schedule with live class indicators.
- **Digital Marksheets:** Subject-wise breakdown (Theory + Internal) with cumulative CGPA and distinction calculations.
- **Fee Payment Simulator:** Secure gateway simulator with instant printable/downloadable payment receipts.
- **Homework &amp; Task Submissions:** Digital assignment submission to subject faculty.
- **Institutional Circulars:** Live notices, event announcements, and examination updates.

## 🛠️ Technology Stack

- **Frontend &amp; UI/UX:** HTML5, CSS3, Vanilla JavaScript (ES6+), Bootstrap 5, FontAwesome 6, Google Fonts (Plus Jakarta Sans, Outfit).
- **Backend / ERP Logic:** PHP &amp; Cloudflare Worker Edge runtime for high availability.
- **Styling Architecture:** Modern Glassmorphism, CSS Custom Properties, Responsive Fluid Grids.
- **Cloud Infrastructure:** Cloudflare Workers Static Assets (Global Edge CDN with 100% uptime).
